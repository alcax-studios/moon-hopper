# 0002: First-person view, and a level generated from code

- **Date:** 2026-11-25
- **Status:** accepted

## Context

The first playable needed a camera perspective, and a way to build a whole forest level and its placeholder art quickly, reproducibly, and in a form an AI agent can edit.

## Decision

- **First person** (the user's call), using a Cinemachine 3 camera hard-locked to the player's head, with procedural animation for the held weapons.
- **The level, prefabs, and materials are generated by an editor script** (`ForestBuilder`), not hand-placed. Placeholder art is low-poly primitives and procedural meshes in the palette colors, and placeholder audio is synthesized at runtime.
- **The UI is built from code** (uGUI and TMP), not authored prefabs.

## Alternatives considered

- Hand-authored scene: slower to iterate, and hard for an agent to change safely.
- Top-down or third-person camera: dropped at the user's request.

## Consequences

- One menu item rebuilds everything, so balance and layout changes are code diffs.
- Hand edits to `Forest.unity` get overwritten on the next build. Move content to prefabs or data first if a hand-authored pass is wanted.
- Swapping in real assets means changing `ForestAssets` to instance imported prefabs instead of primitives.
