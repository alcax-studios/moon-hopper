# 0004: Generated greybox, hand-authored scenes after the art pass

- **Status:** accepted
- **Date:** 2026-11-27

## Context

Every map is generated by an editor builder (`AtriumBuilder`, `PlaygroundBuilder`), and a rebuild wipes any edit made in the scene. That suits greybox: layouts change often and the code is easy to change. Detailed art needs the opposite: modular kit pieces, set dressing, decals, and lighting placed and tuned by hand (by the user directly, or by Claude through the Editor), and kept.

## Decision

- New spaces start as generated greybox (builder code or ProBuilder), built to the level metrics.
- When a space enters its art pass, its scene becomes the source of truth. The builder stops writing that space; from then on it's edited in the scene, through the Editor or the Unity CLI.
- Systems stay data-driven where it helps (item placement tables, loot tables, spawn lists), so a hand-authored scene still reads them.
- The Atrium stays generated until its art pass begins.

## Consequences

- Hand edits in art-pass scenes are safe; greybox spaces still regenerate.
- Each scene must say which mode it's in (a note in `docs/tech/architecture.md`), so nobody rebuilds over finished art.
- Scene files get bigger and merge conflicts are possible; keep one person (or one session) on a scene at a time.
